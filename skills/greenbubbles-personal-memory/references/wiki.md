# Knowledge base layout

The knowledge base is `index.md` plus the articles in `domains/`. Read
[format-markdown.md](format-markdown.md) for the page shape and
[cli.md](cli.md) for the live queries that supply it.

Build and revise those files from `messages list` and `messages search`.
An incremental pass edits the same project. It does not prepare a corpus
and it does not keep a parallel evidence store.
